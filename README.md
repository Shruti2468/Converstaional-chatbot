# Converstaional-chatbot
A lightweight conversational chatbot powered by Qwen2.5-0.5B-Instruct from Hugging Face, built with a Gradio UI.

**Features**
* Real-time token streaming
* Multi-turn conversation (last 5 turns)
* Adjustable sampling (temperature, top_p)
* Clean Gradio UI

Run
python app.py

Model
Qwen/Qwen2.5-0.5B-Instruct -> No API Key required
Small (0.5B) instruction-tuned model for fast local inference.
